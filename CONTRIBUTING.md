# Contribuição

Antes de enviar uma alteração:

1. Execute `npm.cmd run verify`.
2. Confirme que nenhum banco, segredo ou arquivo temporário será versionado.
3. Atualize a documentação quando o contrato da API ou do banco mudar.
4. Prefira commits pequenos e descritivos.

Alterações de dados devem incluir validação de integridade e uma estratégia de rollback.
