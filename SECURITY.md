# Segurança

- Não coloque senhas, tokens, arquivos `.env` ou bancos operacionais no Git.
- Faça backup antes de alterações destrutivas no banco.
- Valide toda entrada recebida pela API.
- Mantenha as integrações externas isoladas e com tratamento de falhas.
- Para reportar um problema sensível, não o publique em uma issue pública.
